プライバシーポリシー

ひろ@AI遊び場（Hiro @ AI Playground）（以下、「当開発者」といいます）は、提供するスマートフォン用アプリケーション「NotiPop」（以下、「本アプリ」といいます）におけるユーザー情報の取り扱いについて、以下の通りプライバシーポリシーを定めます。

1. ユーザーのデータは端末内にのみ保存されます

本アプリが保存するのは、ユーザーが選んだ対象アプリの一覧と、アイコンの大きさ・めり込みの深さ・静かにする条件などの設定だけです。これらは端末内の設定ファイルにのみ保存され、当開発者のサーバーや第三者へ送信されることはありません。当開発者がその内容を受け取ることもありません。

端末の自動バックアップ（Android のバックアップ機能）を有効にしている場合、対象アプリの一覧と設定はユーザーの Google アカウントのバックアップに含まれます。これは Android 端末の機能によるもので、当開発者がその内容を受け取ることはありません。

本アプリが行う通信は、下記の広告の取得に限られます。

2. 通知へのアクセス（通知リスナー）の取り扱い

本アプリの目的は、ユーザーが選んだアプリ（以下、「対象アプリ」といいます）に通知が届いた時、そのアプリのアイコンを画面の端に浮かべ、タップでその通知を開けるようにすることです。そのために Android の「通知へのアクセス」を使います。この許可は、ユーザーが本アプリの画面から設定画面を開いて自分でオンにした場合にのみ動作し、いつでも取り消せます。

  • その場で使うもの … 通知を出したアプリ（パッケージ名）、通知の識別子、通知の種類（常駐・まとめ通知かどうか）、通知の重要度、通知を開いた時の動作。アイコンを出すか・消すかを決め、タップした時に通知を開くために使います。
  • 読まない・保存しないもの … 通知の本文・タイトル・送信者・画像。本アプリはこれらを読み取らず、記録もしません。
  • 通知の情報は、アイコンを表示している間だけメモリ上で使い、ファイルには保存しません。端末の外へ送信することもありません。

3. 端末権限について

  • 通知へのアクセス（通知リスナー） … 第2項の目的に使用します。
  • 他のアプリの上に重ねて表示 … 対象アプリのアイコンを画面の端に浮かべるために使用します。浮かべるアイコンの中に広告を表示することはありません。
  • 電池の最適化の除外（確認ダイアログでの依頼） … 一部の端末では、省電力機能が本アプリを止めて通知が届かなくなるため、ユーザーの確認を得て除外を依頼します。許可しない場合も他の機能はご利用いただけます。
  • インターネット … 広告の取得にのみ使用します。

本アプリは、インストール済みアプリの情報について、ホーム画面から起動できるアプリの名称とアイコンのみを端末内で参照します（対象アプリを選ぶ一覧を表示するため）。すべてのインストール済みアプリを取得する権限（QUERY_ALL_PACKAGES）は使用していません。

連絡先・位置情報・カメラ・マイク・電話・写真やファイルへのアクセス権限は求めません。

4. 広告の配信について

本アプリでは、無料提供および機能維持のため第三者配信の広告サービス「Google AdMob」を利用しています（設定画面の下部にバナー広告を表示します）。広告配信事業者は、ユーザーの興味に応じた広告を表示するために、クッキー（Cookie）や広告識別子（AAID など）を使用してデバイスに関する匿名情報を収集する場合があります。これらに個人を特定できる情報は含まれません。Google AdMob の SDK は、広告の配信と計測のために、IP アドレス（おおよその地域の推定に使われることがあります）、広告 ID などのデバイス識別子、広告の表示・タップなどの操作、SDK の動作に関する診断情報を Google に送信します。本アプリが扱う通知の情報や対象アプリの一覧を AdMob に渡すことはありません。

Google AdMob が収集する情報の詳細およびオプトアウト（情報の送信拒否）方法については、以下の Google のポリシーをご確認ください。

  • Google 広告規約 とプライバシーポリシー

5. 同意の確認が必要な地域のユーザーの方へ

本アプリは、Google 認定の同意管理プラットフォーム（UMP / User Messaging Platform）を使用しています。法令により広告の同意が必要な地域からご利用の場合、広告を読み込む前に同意の確認画面を表示し、その手続きが終わるまで広告の読み込みおよび広告識別子の利用を行いません。同意しない選択をされた場合は、ユーザーの興味に基づかない広告（非パーソナライズ広告）が表示されます。

一度行った選択は、設定画面の下部にある「プライバシー設定」からいつでも変更・撤回できます。この項目は同意の確認が必要な地域からのご利用時にのみ表示されます。

6. 子どものプライバシー

本アプリは、年齢を問わず個人情報を収集しません。13歳未満の児童から意図的に情報を収集することもありません。
