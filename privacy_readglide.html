プライバシーポリシー

ひろ@AI遊び場（Hiro @ AI Playground）（以下、「当開発者」といいます）は、提供するスマートフォン用アプリケーション「ReadGlide」（表示中のページを一定の速さでゆっくり流す、画面の端のつまみ。以下、「本アプリ」といいます）におけるユーザー情報の取り扱いについて、以下の通りプライバシーポリシーを定めます。

1. ユーザーのデータは端末内にのみ保存されます

つまみの位置・長さ・色・濃さ、流す速さ、音量キーの段の数などの設定は、すべて端末内にのみ保存されます。これらが当開発者のサーバーへ送信されることはなく、当開発者がその内容を受け取ることもありません。

本アプリは Android の自動バックアップを無効にしているため、設定がユーザーの Google アカウントのバックアップに含まれることもありません。

本アプリが行う通信は、下記の広告の取得に限られます。設定の内容や、ユーザー補助機能で得た情報が広告の通信に含まれることはありません。

2. ユーザー補助機能（AccessibilityService）の利用について

本アプリは、Android のユーザー補助機能（AccessibilityService API）を、次の目的だけに使います。ユーザー補助機能は、アプリ内の説明に同意し、ユーザー自身が端末の設定でオンにした場合にのみ動作します。

  • ページを流す指の動きの送信 … ユーザーがつまみで流し始めると、画面をなぞる指の動きを本アプリが端末へ送り、表示中のページをゆっくり流します。画面に触れると止まります。
  • つまみ・棒の表示 … 画面の端に、つまみと速さを示す棒を重ねて表示します。
  • 音量キーによる速さの調整 … ページを流している間だけ音量キーを受け取り、速さの上げ下げに使います。流していない間はキーを受け取らず、通常の音量調整のままです。
  • なぞる範囲を決めるための窓と部品の位置の確認 … 前面のアプリの窓の位置と大きさ、スクロールできる部品の範囲、押せる部品とキーボードの位置を見て、流す範囲を決めます。また、前面のアプリ（パッケージ名）が変わったことを知り、別のアプリに切り替わった時に流すのを止めます。ここで見るのは位置・大きさ・アプリ名だけです。

端末の設定画面に「画面の内容を取得」と表示されますが、これは上記の窓と部品の位置を見るために必要な区分です。本アプリは画面の中身（文字・入力内容・パスワードなど）を読み取りません。ユーザー補助機能で得た情報を保存したり、外部へ送信したりすることもありません。また、AI などによる自動判断は行わず、ユーザーが操作したとおりにページを流すだけです。

3. アプリが求める権限について

  • ユーザー補助サービス（BIND_ACCESSIBILITY_SERVICE）… 第2項の目的に使用します。
  • インターネット（INTERNET）・ネットワーク状態の確認（ACCESS_NETWORK_STATE）… 下記の広告の取得にのみ使用します。
  • 広告 ID（com.google.android.gms.permission.AD_ID・ACCESS_ADSERVICES_AD_ID）… 下記の広告の配信と計測にのみ使用します。
  • スリープの防止・裏の処理（WAKE_LOCK・FOREGROUND_SERVICE）… 広告 SDK が通信の予約のために使う権限です。本アプリ自身は使いません。
  • DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION… 利用しているライブラリ（AndroidX）が、アプリ内の受信を他のアプリから守るために定義する、本アプリ専用の権限です（同じ署名のアプリにしか与えられません）。ユーザーに許可を求める画面は出ず、情報の取得にも使いません。

連絡先・位置情報・カメラ・マイク・電話・ストレージへのアクセス権限は求めません。「他のアプリの上に表示」の許可も求めません。アプリ内に、端末の電池の最適化や自動起動の設定画面を開く案内がありますが、これは端末の設定画面を開くだけで、設定の変更はユーザー自身が行います。

4. 広告の配信について

本アプリでは、無料提供および機能維持のため第三者配信の広告サービス「Google AdMob」を利用しています（アプリの設定画面にバナー広告を表示します）。広告配信事業者は、ユーザーの興味に応じた広告を表示するために、クッキー（Cookie）や広告識別子（AAID など）を使用してデバイスに関する匿名情報を収集する場合があります。これらに個人を特定できる情報は含まれません。Google AdMob の SDK は、広告の配信と計測のために、IP アドレス（おおよその地域の推定に使われることがあります）、広告 ID などのデバイス識別子、広告の表示・タップなどの操作、SDK の動作に関する診断情報を Google に送信します。ユーザーの設定や、ユーザー補助機能で得た情報を AdMob に渡すことはありません。

Google AdMob が収集する情報の詳細およびオプトアウト（情報の送信拒否）方法については、以下の Google のポリシーをご確認ください。

  • Google 広告規約 とプライバシーポリシー

本アプリは、Google 認定の同意管理プラットフォーム（UMP / User Messaging Platform）を使用しています。法令により広告の同意が必要な地域からご利用の場合、広告を読み込む前に同意の確認画面を表示し、その手続きが終わるまで広告の読み込みおよび広告識別子の利用を行いません。

5. 子どものプライバシー

本アプリは、年齢を問わず個人情報を収集しません。13歳未満の児童から意図的に情報を収集することもありません。
