「AI に聞く」を使うための API キーの取り方

当開発者のアプリ（MainteTree など）の「AI に聞く」は、あなた自身が各 AI 会社から取得した API キーを使って動きます。このページでは、なぜキーが要るのか、いくらかかるのか、どこで取るのかを順に説明します。初めての方は「まずはこれ（Gemini）」だけ読めば十分です。

1. なぜキーが要るの？

ChatGPT や Gemini のような AI は、会社のサーバーで動いています。アプリから AI に質問を送るには、「誰が使っているか」を示す合言葉（API キー）を付けて送る必要があります。当開発者がキーをまとめて用意すると、アプリが無料のまま当開発者に AI 利用料が請求され続けるため、使う人が自分のキーを持ち込む方式にしています。

キーが無くても、アプリの本来の機能（記録・点検・写真・CSV など）はすべて使えます。「相談文を共有」で文章だけを取り出し、ChatGPT アプリなどに貼り付ける使い方もできます。

2. いくらかかるの？

アプリ自体は無料です。AI の利用料は各社からあなたのアカウントに直接請求されます（当開発者は一切受け取りません）。会社によって「無料枠あり」と「前払い必須」に分かれます。

会社無料枠ひとこと
Gemini（Google）無料枠ありFlash 系モデルが無料。まずはこれ
Groq無料枠あり1日1,000回・1分30回まで無料。応答が速い
Cerebras条件付きカード不要の無料枠は 2026-08 に終了。支払い方法を登録すると $5 クレジット（30日で失効）
OpenRouter無料モデルあり「:free」モデルは無料（クレジット無しだと1日50回）
Mistral無料枠ありStudio の Free モードで開始できる
ChatGPT（OpenAI）前払いクレジットを購入して使う
Claude（Anthropic）前払いクレジットを購入して使う
Grok（xAI）前払いクレジットを入れてからキー発行
1回の相談は数円以下のことがほとんどですが、金額・無料枠の条件は各社が予告なく変えます。必ず各社の料金ページで最新を確認してください。前払いの会社は、使い過ぎを防ぐために「上限額」の設定をおすすめします。

3. キーは安全？

  • キーはあなたの端末の中だけに暗号化して保存されます。バックアップにも含まれず、当開発者へ送られることはありません。
  • キーはパスワードと同じです。人に見せない・スクリーンショットに写さない・SNS に貼らないでください。
  • 漏れたと思ったら、各社のキー管理ページでそのキーを削除すれば無効になります。作り直せば済みます。

4. どこに入れるの？（MainteTree 直接 or AiKeyHub）

入れ方は2つあります。当開発者の AI 付きアプリを2つ以上使うなら AiKeyHub、1つだけなら直接で十分です。

  • MainteTree に直接: MainteTree の「AI 設定」→ 使いたい会社の「＋ AI を追加」→ API キー欄に貼り付け。
  • AiKeyHub にまとめて: AiKeyHub アプリにキーを1回入れると、対応するアプリ（MainteTree など）はそれを借りて使えます。MainteTree 側では「AI 設定」→「AiKeyHub の設定を使う」を ON にし、AiKeyHub 側で MainteTree を承認してください。

5. まずはこれ: Gemini（Google）のキーを取る 無料枠あり

Google アカウントがあれば数分で取れて、Flash 系モデルは無料枠で使えます。カード登録は不要です。

  1. スマホのブラウザで Google AI Studio の API キーページ を開き、Google アカウントでログインします。
  2. 「API キーを作成（Create API key）」を押します。プロジェクトを聞かれたら「新しいプロジェクトで作成」を選びます。
  3. 表示されたキー（AIza… で始まる文字列）の横のコピーボタンを押します。
  4. アプリに戻り、「AI 設定」→ Gemini の API キー欄に貼り付けて保存します。
  5. 「モデル一覧を取得」を押すと、そのキーで使えるモデルがメニューに並びます。無料枠で使うなら Flash 系を選びます。
利用規約と料金は Gemini API の料金ページ を確認してください。無料枠は1日あたりの回数に上限があり、超えると「上限に達しました」と返ってきます（翌日戻ります）。

最終確認日: 2026-09-07

6. 他の会社のキーを取る

会社名をタップすると手順が開きます。どの会社も流れは同じで、「アカウント作成 → キー管理ページ → 新しいキーを作成 → コピー → アプリに貼り付け」です。

Groq 無料枠あり
  1. Groq Console の API Keys を開き、Google などでサインアップします。
  2. 「Create API Key」→ 名前を付けて作成 → 表示されたキー（gsk_…）をコピーします。
  3. アプリの「AI 設定」→ Groq の API キー欄に貼り付けます。

無料枠は 1 分 30 回・1 日 1,000 回まで（レート制限の公式ページ）。オープンモデル（gpt-oss・Llama など）を高速に動かす会社です。

最終確認日: 2026-09-07

Cerebras 条件付き
  1. Cerebras Cloud Console でアカウントを作ります。
  2. 「Billing」で支払い方法を登録します（登録すると $5 分のクレジットが付き、30 日で失効します。カード不要の無料枠は 2026 年 8 月に終了しました）。
  3. 左メニューの「API Keys」→ 新しいキーを作成 → コピーします。
  4. アプリの「AI 設定」→ Cerebras の API キー欄に貼り付けます。

料金は Cerebras の料金ページ を確認してください。料金ページに「無料クレジット」と残っていても、支払い方法の登録なしでは 402（支払いが必要）が返ります（2026-09-05 に実測）。

最終確認日: 2026-09-07

OpenRouter 無料モデルあり
  1. OpenRouter の Keys ページ を開き、サインアップします。
  2. 「Create Key」→ 名前を付けて作成 → 表示されたキー（sk-or-…）をコピーします。
  3. アプリの「AI 設定」→ OpenRouter の API キー欄に貼り付けます。

1 つのキーで多くの会社のモデルが使えます。モデル名が「:free」で終わるものは無料ですが、クレジット無しだと 1 日 50 回まで（$10 以上入れると 1 日 1,000 回）。詳細は OpenRouter の FAQ。

最終確認日: 2026-09-07

Mistral 無料枠あり
  1. Mistral Studio（旧 La Plateforme） でアカウントを作り、Free モードで有効化します。
  2. 「API Keys」→ 新しいキーを作成 → コピーします。
  3. アプリの「AI 設定」→ Mistral の API キー欄に貼り付けます。

Free モードの条件（電話番号認証など）や上限は Mistral の Quickstart を確認してください。

最終確認日: 2026-09-07

ChatGPT（OpenAI） 前払い
  1. OpenAI Platform の API keys を開き、ログインします（ChatGPT のアカウントと同じで構いませんが、ChatGPT Plus の料金とは別です）。
  2. 「Create new secret key」→ 名前を付けて作成 → 表示されたキー（sk-…）をコピーします。この画面を閉じると二度と表示されません。
  3. 「Billing」でクレジットを購入します（数ドルから）。上限額（Usage limits）も設定しておくと安心です。
  4. アプリの「AI 設定」→ ChatGPT の API キー欄に貼り付けます。

料金は OpenAI API の料金ページ を確認してください。

最終確認日: 2026-09-07

Claude（Anthropic） 前払い
  1. Claude Console の API Keys を開き、アカウントを作ります（Claude アプリの Pro 契約とは別です）。
  2. 「Create Key」→ 名前を付けて作成 → 表示されたキー（sk-ant-…）をコピーします。
  3. 「Billing」でクレジットを購入します。
  4. アプリの「AI 設定」→ Claude の API キー欄に貼り付けます。

料金は Claude の料金ページ を確認してください。

最終確認日: 2026-09-07

Grok（xAI） 前払い
  1. xAI Console でアカウントを作ります。
  2. 先に「Billing」でクレジットを入れます（公式ガイドが「クレジットを入れてから API を使う」と案内しています）。
  3. 「API Keys」→ 新しいキーを作成 → コピーします。
  4. アプリの「AI 設定」→ Grok の API キー欄に貼り付けます。

料金は xAI のモデル一覧（料金付き） を確認してください。

最終確認日: 2026-09-07

AiKeyHub には上記以外の会社（DeepSeek・Kimi・GLM・Qwen・Together AI・Fireworks AI・Perplexity・NVIDIA NIM）も入っています。流れは同じで、各社のコンソール（開発者向けページ）の「API Keys」から作ってコピーしてください。無料枠の有無は会社ごとに違うので、各社の料金ページを確認してください。

7. アプリに戻って貼り付ける

  1. コピーしたキーを、アプリの「AI 設定」→ その会社の API キー欄に貼り付けて保存します。
  2. 「モデル一覧を取得」を押して、使うモデルを選びます（無料枠のある会社は無料のモデルを）。
  3. 記録や点検の画面から「AI に聞く」を押して、返事が来れば完了です。
AiKeyHub に入れた場合は、MainteTree の「AI 設定」で「AiKeyHub の設定を使う」を ON にし、AiKeyHub 側で MainteTree を承認してください。以後、キーの変更は AiKeyHub だけで済みます。

8. うまくいかないとき

  • 「キーが無効」と出る: コピー時に前後の空白や改行が混ざっていないか確認します。キーを作り直すのが早いです。
  • 「上限に達した」「429」と出る: 無料枠の回数を使い切っています。翌日まで待つか、別の会社を追加してください。複数の会社を入れておくと「Auto」が空いている社へ自動で切り替えます。
  • モデル一覧が空: 前払いの会社はクレジットが 0 だと一覧も返ってきません。Billing を確認してください。
  • 手順が画面と違う: 各社が画面をよく変えます。上の「最終確認日」より新しい変更の可能性があるので、公式ページの案内を優先してください。気づいたら下記の連絡先へ教えていただけると助かります。
